# E2-03 — Build the responsive application shell

## Status

`completed`

## Scope

Provide the shared Rails layout for the responsive Bootcamper experience. The
shell exposes Home, Workshop, Tasks, Team, Calendar, and Profile in a desktop
sidebar and mobile bottom navigation. It does not implement destination pages,
authentication-aware links, or theme switching.

## Approved decisions

- Use the E2-01 semantic Tailwind tokens and Rails server-rendered views.
- Use a desktop sidebar at `md` and above and mobile bottom navigation below
  `md`, with content padding for the fixed mobile bar.
- Keep navigation destinations as future-facing paths until their functional
  tickets add controllers and routes.
- Use Ukrainian copy with English fallback through I18n.
- Avoid JavaScript: the shell needs no interactive state beyond normal links.

## Changes

- Replaced the generic layout with semantic shell landmarks and a skip link.
- Added reusable navigation partials for desktop and mobile presentations.
- Added localized navigation labels and decorative text icons.
- Added request coverage for landmarks, labels, and the six-item navigation.
- Documented shell breakpoint and ownership conventions in the design system.
