## Technical decisions

### TD-1 — Explicit support loading

- Context: Test dependencies must be available consistently without hidden global behavior.
- Decision: Load `spec_helper` and sorted support files from the Rails helper; keep each library’s configuration in its own support file.
- Alternatives: Require support ad hoc in individual specs or add broad shared helpers; rejected because they obscure setup or expand scope.
- Consequences: New and existing specs share predictable integrations while behavior remains in request/model examples.
