## Technical decisions

### TD-1 — Server-rendered static prototype

The map is a Rails partial rendered with illustrative locals. No JavaScript,
database records, progress service, or authorization was introduced before the
underlying product concepts exist.

### TD-2 — State labels accompany visual markers

Markers and semantic colors reinforce state, while visible text labels carry
the meaning. E2-06 will perform the complete keyboard, reduced-motion, and text
equivalent verification.
