## Technical decisions

### TD-1 — Keep Rails credentials authoritative

- Context: E1-02 config reads database settings from encrypted per-environment credentials while Compose provisions PostgreSQL.
- Decision: Keep `RAILS_MASTER_KEY` and `POSTGRES_PASSWORD` explicit; document that the Compose password must equal encrypted `database.password`, with development credentials for the development smoke path and test credentials for test commands.
- Alternatives: Reintroduce environment-variable database fallbacks or commit secrets; rejected because they conflict with E1-02 and secret-handling requirements.
- Consequences: Fresh clones require a one-time local credential setup and CI must provide matching environment-specific secrets.
