# User administration

## Product problem

Bootcamper cannot operate safely when administrators cannot inspect, correct, create, update, deactivate, reactivate, role-manage, or remove user accounts.

## Intended outcome

Authorized admins list and find users, inspect status and roles, create or update accounts for support, manage roles, suspend and restore access with a reason, and preserve required learning history. Safeguards prevent accidental loss of the last essential administrator.

## Evidence

- [Moodle user administration](https://docs.moodle.org/310/en/admin/uploaduser), verified 2026-08-30, distinguishes account creation, confirmation, role assignment, deletion, suspension, and reactivation.

## Scores

- User benefit: 4/5
- Progressiveness: 2/5
- Business value: 5/5
- Confidence: 5/5

## Priority rationale

This is an operational prerequisite before open registration creates real accounts. It depends on roles and belongs within, but remains distinct from, the admin workspace.
