# Mentor-guided learning journey

## Product problem

Self-paced content alone does not help a learner choose the right goal, adapt the path, overcome blockers, or translate learning into real progress.

## Intended outcome

A learner and mentor share an explicit goal, relevant learning program, milestones, next actions, progress evidence, and periodic reflection. They can adjust the journey deliberately and complete, pause, or close it with a recorded outcome.

## Evidence

- MentorCruise emphasizes goal support, continuity, exercises, and work review; verified 2026-08-30.
- MENTOR research highlights compatibility, structure, monitoring, support, and deliberate closure; verified 2026-08-30.

## Scores

- User benefit: 5/5
- Progressiveness: 5/5
- Business value: 5/5
- Confidence: 5/5

## Priority rationale

This is Bootcamper's differentiator, but it should build on the first defined content and assessment flows so mentoring has shared learning context rather than becoming generic coaching.
